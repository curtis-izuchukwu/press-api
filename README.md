# FlightDeck API

FlightDeck API is a serverless REST API built with Cloudflare Workers and TypeScript. It generates structured undergraduate-level revision material from study inputs such as subject, topic, difficulty, question count, and format.

The project is designed as a professional portfolio backend and will later support **PararePilot**, an adaptive study tracker.

## Current status

FlightDeck API currently supports:

- Health check endpoint
- Worksheet generation endpoint
- Runtime input validation
- Structured worksheet JSON responses
- Workers AI integration
- Static fallback generation if AI output fails validation
- Cloudflare KV caching
- Cloudflare D1 persistence
- Worksheet history endpoint
- Rate limiting for generation requests
- Automated tests with Vitest

## Endpoints

### GET `/health`

Returns basic service status metadata.

Example response:

```json
{
  "status": "ok",
  "service": "FlightDeck API",
  "version": "0.1.0"
}
```

---

### POST `/generate`

Generates an undergraduate-level revision worksheet.

Example request:

```json
{
  "subject": "Computer Science",
  "topic": "Binary Search",
  "difficulty": "medium",
  "questionCount": 3,
  "format": "short-answer"
}
```

Example response:

```json
{
  "metadata": {
    "service": "FlightDeck API",
    "version": "0.1.0",
    "subject": "Computer Science",
    "topic": "Binary Search",
    "difficulty": "medium",
    "questionCount": 3,
    "format": "short-answer",
    "generatedAt": "2026-06-04T14:36:35.107Z",
    "academicLevel": "undergraduate",
    "mode": "ai",
    "cache": "miss"
  },
  "questions": [
    {
      "id": 1,
      "type": "short-answer",
      "question": "What is the key difference between binary search and linear search?",
      "answer": "Binary search repeatedly halves a sorted search space, while linear search checks each item sequentially.",
      "markScheme": [
        "Identifies that binary search requires sorted data.",
        "Explains that binary search reduces the search space.",
        "Compares the time complexity with linear search."
      ],
      "marks": 3
    }
  ]
}
```

Generation modes:

```text
ai      = all questions generated successfully by Workers AI
mixed   = some questions generated by AI, some fallback questions used
static  = fallback generation used for all questions
```

Cache states:

```text
miss = generated fresh and stored in KV
hit  = returned from KV cache
```

---

### GET `/history`

Returns recently generated worksheet records stored in Cloudflare D1.

Example response:

```json
{
  "metadata": {
    "service": "FlightDeck API",
    "version": "0.1.0",
    "count": 1
  },
  "worksheets": [
    {
      "id": "79ed2162-6631-4a2e-bdae-efae19999d48",
      "subject": "Computer Science",
      "topic": "Graph Traversal",
      "difficulty": "medium",
      "question_count": 3,
      "format": "short-answer",
      "academic_level": "undergraduate",
      "mode": "mixed",
      "cache_status": "miss",
      "created_at": "2026-06-04T15:15:36.837Z"
    }
  ]
}
```

## Validation rules

`POST /generate` expects:

| Field | Type | Rules |
|---|---|---|
| `subject` | string | Required, 1–80 characters |
| `topic` | string | Required, 1–120 characters |
| `difficulty` | string | `easy`, `medium`, or `hard` |
| `questionCount` | number | Integer from 1 to 10 |
| `format` | string | `short-answer`, `multiple-choice`, or `mixed` |

Invalid requests return a `400` validation error.

## Rate limiting

`POST /generate` is rate limited because it can call Workers AI.

Current limit:

```text
10 requests per IP per 60 seconds
```

When exceeded, the API returns:

```json
{
  "error": "Too Many Requests",
  "message": "Rate limit exceeded. Please try again later."
}
```

## Local development

Install dependencies:

```bash
npm install
```

Run type checking:


Run tests:


```bash
npm run dev
```

Health check:

```text
http://127.0.0.1:8787/health
```

Generate worksheet:

```powershell
Invoke-RestMethod `
  -Uri http://127.0.0.1:8787/generate `
  -Method POST `
  -ContentType "application/json" `
  -Body '{
    "subject": "Computer Science",
    "topic": "Binary Search",
    "difficulty": "medium",
    "questionCount": 3,
    "format": "short-answer"
  }'
```

View history:

```text
http://127.0.0.1:8787/history
```

## Cloudflare resources

This project uses the following Cloudflare bindings:

```text
AI                 Workers AI binding
FLIGHTDECK_CACHE   KV namespace for caching generated worksheets and rate-limit state
DB                 D1 database for worksheet history
```

## D1 migrations

Apply local migrations:

```bash
npx wrangler d1 migrations apply flightdeck-db --local
```

If needed, execute the migration file directly:

```bash
npx wrangler d1 execute flightdeck-db --local --file ./migrations/0001_create_worksheets.sql
```
